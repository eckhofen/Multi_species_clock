# For reviewers

Please download (Password will be provided) the required [data](https://saco.csic.es/s/afCwqao7w9XftAy). These contain the processed methylation profiles for all species, some of which are in process to be made public. 

Unzip the file into the `01_data/01_raw_private` folder, then run the pipeline C manually as described in the `README.md` or use the convenience script `02_code/02_helpers/C_pipeline.R`.

For tracking which outputs correspond to the results shown in the paper, please refer to the `replicate_results.md` docs.
