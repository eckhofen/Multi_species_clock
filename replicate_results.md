# Purpose

This document maps each numerical result, figure, and table reported in the main text of the manuscript to the exact script and output file in this repository. It is meant for reviewers (and any user reproducing the work) to be able to locate, run, and verify every reported finding.

For the full pipeline overview, installation requirements and data sources see `README.md`. 

# Quick orientation

- **Pipeline scripts** live in `02_code/01_pipeline/` and are numbered in the order they must be run.
- **Pre-processing scripts** (only required if starting from raw RRBS reads — zebrafish) live in `02_code/00_pre-processing/ZF/`.
- **Helper scripts** (package install, plot style, shared theme) live in `02_code/02_helpers/`.
- **Inputs** live in `01_data/` (`01_raw_private/` for raw inputs, `04_metadata/` for metadata, `02_external_server_outputs/` for alignment outputs, `03_intermediate/` for all generated objects).
- **Final figures and tables** are written to `03_results/01_figures/` and `03_results/02_tables/`.

# Tables

### Table 1 — Dataset summary (per-species CpG counts, sequencing method, sample size, etc.)

The reported per-species CpG counts (85,735 AC ... 757,883 ZF) come from the raw methylation data loaded in `02b_methylation_extraction.R` and `09_auto-correlation.R`. The number of *extended sequences* (13,641 AC; 24,410 AS; 18,049 EH; 172,397 ZF) is reported in the metadata CSVs produced by `01a_CpGs_to_sequences.R` (`01_data/02_external_server_outputs/01_sequences/*_metadata_1000bp.csv`, one row per extended window). Sample sizes per species come from `01_data/04_metadata/metadata.RData` (object `meta_data`, summarised in `00c_data_overview.R`).

### Sup. Table S1 — Alignment rates to alternative reference genomes

The alignment rates to GRCh38 reported in the main text (33.6 % AC, 9.6 % AS, 37.1 % EH, 14.0 % ZF) are reported by bowtie2 at the end of each `01c_align_to_rgenome.sh` run. Alignment runs against the per-species own assemblies (used to compare against hg38) were performed using the same script with `path_rgenome` switched to each species' genome.

### Sup. Table S2 — Genes overlapping the 40 selected SMR CpGs

Produced by `07_annotation_prep.R`. Output:
- `03_results/02_tables/gene_list_selected.csv` — genes / lncRNAs overlapping the 40 selected CpGs per species (used in the GenAge cross-check in the main text).
- `03_results/02_tables/gene_list_SMR.csv` — all genes overlapping any CpG in any SMR (broader background table).

The GenAge cross-check itself is a manual comparison against `01_data/03_intermediate/08_annotation/genage_human.csv`

# Reproducing the pipeline from scratch

Following the workflow tiers given in `README.md`:

- **Tier A (raw reads)** — pre-process zebrafish RRBS with the scripts in `02_code/00_pre-processing/ZF/01_…08_` (the other three species' bisRAD-seq libraries must be pre-processed externally per the original publications; the pre-processed methylation tables are required as inputs to step 1a). Then continue with Tier B.
- **Tier B (methylation tables available)** — run `02_code/01_pipeline/` scripts in order: `00a → 00b → 00c → 01a → 01b → 01c → 02a → 02b → 03 → 04 → 05a → 05b → 06 → 07 → 08 → 09 → 10`.
- **Tier C (no raw data)** — intermediate `.Rdata` objects shipped in `01_data/03_intermediate/` allow re-running from script `03_SMR_plotting.R` onward to regenerate every figure and statistic above without the raw alignment step.

The expected runtime end-to-end on a laptop, excluding pre-processing of raw reads, is on the order of an hour (the alignment step `01c_align_to_rgenome.sh` and the autocorrelation step `09_auto-correlation.R` dominate the runtime; everything else completes in minutes).
